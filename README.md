# Blokido website

Landing page, privacy policy and terms of use for **Blokido**, a block puzzle game for iOS and Android.

Live: https://serhatovic73.github.io/blokido/

- Privacy policy: https://serhatovic73.github.io/blokido/privacy.html (Türkçe: `/tr/privacy.html`)
- Terms of use: https://serhatovic73.github.io/blokido/terms.html (Türkçe: `/tr/terms.html`)

The pages are generated in 16 languages from the game's own texts (`_build/data.json`).
After editing texts or styles, rebuild with:

```
node _build/build.js
```
